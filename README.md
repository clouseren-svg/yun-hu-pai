# 云胡牌 🀄

> 手机里的满番爽局——在手机上过一把胡大牌的瘾。
> 由 Kimi 仿「云吸烟」思路复刻：把病毒式小程序的"夸张演出 + 感官互动"套路搬到麻将桌上。
> **纯属娱乐，不赌一分钱。**

纯静态手机网页小产品（预览版），无框架、无构建步骤，GitHub Pages 直接可跑。

## 玩法

1. **开机屏**：霓虹招牌下点「开局」。
2. **选番型**：清一色 / 七对子 / 杠上开花 / 海底捞月 / 大三元 / 国士无双，挑一手想胡的大牌，点「上桌」。
3. **牌桌**：点发光牌墙「摸牌」。按牌谱摸打几巡后进入听牌（金横幅提示"听：X"），再摸一张就是关键张——
   - 点大红「胡！」按钮，或
   - 点左下「喊胡」开麦克风，**真的喊一嗓子**也能胡（音量峰值触发；权限被拒/不支持时静默降级回按钮，不弹窗糊脸）。
4. **胡牌演出**：关键牌拍桌（移动端震动）、书法「胡！」砸屏、番型横批展开、金币雨 + 烟花、番数滚动，最后彩蛋文案轮换。
   - 「再来一局」同番型重开；「换个番型」回选牌；「炫耀一下」复制分享文案。

骰子可以点着玩；右上角全局静音。

## 本地预览

```bash
cd yun-hu-pai
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

或直接双击 `index.html`（麦克风「喊胡」需要 localhost 或 HTTPS 安全上下文，`file://` 下会自动降级为按钮模式）。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单页结构：开机屏 / 选番型 / 牌桌 / 胡牌结算 四阶段 |
| `style.css` | 全部样式：港片棋牌室 × 霓虹 × 国潮；麻将牌面纯 CSS 绘制；桌面端手机壳边框 |
| `audio.js` | WebAudio 现场合成音效（摸牌哒声、锣声 + 上升五声音阶、金币叮当），无外部音频 |
| `tiles.js` | 牌数据模型 + DOM 牌面渲染 + 六种番型的完整摸打牌谱（均推导为合法胡牌型） |
| `particles.js` | Canvas 粒子：金币雨 + 烟花 |
| `app.js` | 状态机、摸打/听牌/胡牌交互、麦克风喊胡、结算与分享、调试跳转 |

## 调试入口（URL hash）

- `#stage=select` / `#stage=table&fan=guoshi` / `#stage=table&fan=guoshi&ff=tenpai` / `#stage=win&fan=guoshi&instant=1`
- 追加 `&debug=1`：JS 错误写入 `<html data-js-error>`，便于无头浏览器排查
- `#stage=table&fan=guoshi&autoplay=1`：自动走完整摸打 → 胡牌流程（端到端自测用）

## 已知限制

- 麦克风「喊胡」依赖 `getUserMedia`，仅在安全上下文（HTTPS / localhost）可用；`file://` 或权限被拒时静默降级为按钮。
- 中文字体走 Google Fonts CDN，离线环境回落到系统楷体/宋体，气质略减但不影响功能。
- iOS Safari 的 `navigator.vibrate` 不支持，震动仅在 Android 等支持设备上生效。
- 番数/得分为演出效果，牌谱按真实麻将规则编排但不构成完整对局 AI。
