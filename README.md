# 云胡牌 🀄

> 手机里的满番爽局——真规则四人麻将小网页。
> 由 Kimi 仿「云吸烟」思路复刻并升级为完整对局：**港片棋牌室 × 霓虹招牌 × 国潮**的包装下，是一套真摸打、真吃碰杠、真计番的四人麻将。
> **纯属娱乐，不赌一分钱。**

纯静态、无框架、无构建步骤，GitHub Pages 直接可跑。支持 PWA（可"添加到主屏幕"）。

## 玩法

1. **开机屏**点「开局」→ 2. **选场子** → 3. **上桌**：
   - **推倒胡 · 新手场**（推荐）：能胡就胡；推荐出牌金光提示、听牌横幅报听、自动理牌。
   - **计番场 · 老雀友**：8 番起胡，无任何辅助。
4. 东风圈四局一场，按总账排座次。

操作：点手牌选中（抬起），再点一下 / 双击 / 上滑 打出。别人打的牌你能吃/碰/杠/胡时会弹声明按钮，**5 秒不点自动放弃**。麦克风「喊胡」彩蛋：开启后，能胡时真的喊一嗓子即成（权限被拒自动降级为按钮，不弹窗糊脸）。

## 规则集（大众规则 · 简化国标）

- 136 张：万/筒/条各 1-9×4 + 东南西北中发白×4，无花牌。四人局，玩家坐东，庄 14 张先打。
- 流程：洗牌码墙 → 掷骰定庄 → 发牌 → 摸打循环 → 单局计分 → 连庄/轮庄 → 四局一场 → 总结算排行。荒庄（牌墙摸尽）流局，本场重开不计分。
- 声明：吃（仅限上家弃牌）、碰、杠（明杠/暗杠/补杠，杠后从**牌墙尾**补牌）、胡（自摸/点炮）、**抢杠胡**（抢补杠）。多家可胡时按出牌者下家起就近优先；优先级 **胡 > 碰/杠 > 吃**。
- 胡牌牌型：标准 4 副 + 1 将（含副露/门前两种形态）、七对子、国士无双（十三幺，十三面听）。

## AI 陪练

基于向听数（shanten）的启发式：打牌保留搭子、先打孤立字牌/幺九；碰杠以不向听恶化为界（听牌不拆杠）；吃仅在显著改善向听时（仅下家）；能胡必胡。出牌节奏 0.6~1.2 秒随机延时。

## 本地运行

```bash
cd yun-hu-pai
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

麦克风「喊胡」需要 localhost / HTTPS 安全上下文；`file://` 直开也能玩（自动降级）。

## 测试

```bash
node test.js    # 105 项断言：牌型正反例 / 七对子 / 十三幺 / 副露胡牌 / 杠补 / 抢杠胡 / 番种与明细一致性 / 计分公式 / 整场冒烟
```

## 部署

GitHub Pages：把整个 `yun-hu-pai/` 目录推到仓库根（或 `docs/`），Settings → Pages 选择对应目录即可。全部为相对路径，无需任何构建。

## 技术架构

| 文件 | 职责 |
| --- | --- |
| `engine.js` | 纯逻辑引擎：牌模型、分解枚举、胡牌判定（含副露）、向听数、17 番种计分、得分与千分位格式化。浏览器/node 双端 |
| `ai.js` | AI 决策：向听优先打牌、声明权衡 |
| `game.js` | 对局状态机：整场/单局/回合流程、声明裁决、杠补、荒庄、连庄轮庄，经 hooks 与 UI 解耦 |
| `app.js` | UI 控制器：六阶段舞台、牌桌渲染、声明弹窗（5s 倒计时）、胡牌演出、引导页、麦克风喊胡 |
| `tiles.js` | 麻将牌 DOM/CSS 绘制（万/筒/条点阵、字牌书法体、牌背） |
| `audio.js` | WebAudio 现场合成音效：洗牌、摸打、吃碰杠、锣声、金币，无外部音频 |
| `particles.js` | Canvas 金币雨 + 烟花 |
| `test.js` | node 测试套件（105 断言） |
| `manifest.json` + `icon-*.png` + `og.png` | PWA 与社交分享资源（图标由 `tools/gen_icons.py` 用 PIL 生成） |

### 调试入口（URL hash）

- `#stage=mode|tutorial|win|match`：直达对应界面
- `#stage=table&seed=7&mode=rookie`：种子可复现的真开局
- `#autoplay=1&seed=7`：AI 代打整场到总结算（演示/验收用，配 `&fast` 加速）

## 已知限制

- 麦克风需安全上下文；iOS Safari 不支持 `navigator.vibrate`。
- 字体走 Google Fonts CDN，离线回落系统楷体/宋体。
- 规则为简化大众版：无花牌、无立直/振听、无一炮多响（就近截胡）、未设王牌堆（杠补与摸打共用牌墙两端）。
- AI 为启发式陪练，不保证竞技强度。
